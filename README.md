# java-weather-service

Консольный сервис погоды: практическое задание к модулю 6 курса «Программирование на языке Java» (МИФИ, SkillFactory). Делает GET-запрос к API Яндекс Погоды, выводит весь ответ, текущую температуру и среднюю дневную температуру по прогнозу.

## Что нужно

- Java 21 и Maven 3.9 или новее.
- Ключ API Яндекс Погоды: https://yandex.ru/pogoda/b2b/console/home

## Запуск

```bash
export YANDEX_WEATHER_KEY=ваш-ключ
mvn -q compile exec:java -Dexec.args="55.75 37.62 5"
```

Аргументы: широта, долгота и число суток прогноза от 1 до 7. Без аргументов берутся координаты Москвы (55.75, 37.62) и 7 суток.

Ключ уходит в заголовке `X-Yandex-Weather-Key`. В коде его нет: программа читает его из переменной окружения `YANDEX_WEATHER_KEY`.

## Что выводит

1. Адрес запроса: `GET https://api.weather.yandex.ru/v2/forecast?lat=...&lon=...&limit=...`.
2. Весь ответ сервиса в формате JSON, как есть.
3. Текущую температуру из `fact.temp`.
4. Среднюю дневную температуру: среднее арифметическое `forecasts[*].parts.day.temp_avg` по первым `limit` суткам. Параметр `limit` идёт и в запрос, и в расчёт.

## Пример

```text
Запрос: GET https://api.weather.yandex.ru/v2/forecast?lat=55.75&lon=37.62&limit=5
Полный ответ сервиса:
{"now":1791214943,"now_dt":"2026-10-05T15:42:23.833245Z","info":{"n":true,"url":"https://yandex.ru/pogoda/?lat=55.75\u0026lon=37.62", ...

Текущая температура (fact.temp): 11 °C
Средняя дневная температура за 5 сут. (среднее forecasts[*].parts.day.temp_avg): 13.8 °C
```

В примере JSON сокращён, программа печатает его целиком (около 45 КБ).

## Тесты

```bash
mvn -q test
```

Тесты проверяют разбор аргументов, извлечение `fact.temp` и расчёт средней температуры на настоящем ответе API, сохранённом в `src/test/resources`.
